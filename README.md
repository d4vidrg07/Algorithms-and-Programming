# Algorithms and Programming

Exercises and exams from the **Algorithms and Programming** course of my Computer Engineering degree at ULPGC (University of Las Palmas de Gran Canaria). All solutions are written in **Python**.

The exercises are organized by topic rather than by week. Each one has its own folder with a README that explains the problem, my approach and how to run it.

## Exercises

| Topic | Exercise | What it practices |
|---|---|---|
| Lists | [Order Crossover](lists/order-crossover) | Order crossover operator from genetic algorithms: slicing, circular traversal and list membership. |
| Strings | [Calibration sum](strings/calibration-sum) | Scanning strings from both ends, edge cases and unit tests with `pytest`. |

More exercises are added as the course progresses: graphs (BFS), backtracking (N queens), dynamic programming (knapsack) and past exams.

## Structure of each exercise

- `solve.py`: my solution.
- `main.py` and `utils.py`: course template that handles input and output (when the exercise includes them).
- `README.md`: statement, approach, example and complexity.
- Sample input or tests when available.
